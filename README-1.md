# CryptoHarvest - PWA для управления крипто кранами

Полнофункциональное прогрессивное веб-приложение для автоматизированного управления криптовалютными кранами с отслеживанием доходов, управлением кошельками и синхронизацией данных.

## 🚀 Возможности

- **📊 Панель управления** - В реальном времени отслеживание доходов в BTC, ETH, LTC и USD
- **⚡ Автоматизация** - Автоматический сбор из активных кранов
- **💰 Управление кошельками** - Сохранение адресов кошельков с валидацией
- **🔗 Управление кранами** - Добавление, удаление и включение/отключение кранов
- **📱 PWA функции** - Работает как приложение на мобильных устройствах
- **📴 Офлайн режим** - Работает без интернета (с кешированными данными)
- **💾 Персистентные данные** - Все данные сохраняются локально в localStorage
- **📦 Экспорт/Импорт** - Резервное копирование данных в JSON формате
- **🎨 Темный режим** - Оптимизирован для глаз с современным дизайном

## 🔧 Развертывание

### Вариант 1: Локальное использование

1. **Скачайте файлы:**
   ```
   index.html
   manifest.json
   sw.js
   ```

2. **Запустите локальный сервер** (необходимо для работы Service Worker):
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js
   npx http-server
   ```

3. **Откройте в браузере:**
   ```
   http://localhost:8000
   ```

### Вариант 2: Развертывание на веб-хостинге

1. **Загрузите файлы на хостинг:**
   - `index.html`
   - `manifest.json`
   - `sw.js`

2. **Убедитесь, что ваш хостинг поддерживает:**
   - HTTPS (обязательно для Service Workers)
   - Правильные MIME типы

3. **Настройте CORS заголовки (если необходимо):**
   ```
   Access-Control-Allow-Origin: *
   ```

### Вариант 3: Docker контейнер

```dockerfile
FROM node:18-alpine

WORKDIR /app
COPY . .

EXPOSE 3000
CMD ["npx", "http-server", "-p", "3000"]
```

Запуск:
```bash
docker build -t cryptoharvest .
docker run -p 3000:3000 cryptoharvest
```

## 📖 Руководство пользователя

### Начало работы

1. **Откройте приложение** на любом устройстве через веб-браузер

2. **Добавьте кошельки:**
   - Перейдите на вкладку "Wallets"
   - Введите адреса ваших кошельков для BTC, ETH, LTC
   - Данные сохранятся автоматически

3. **Добавьте краны:**
   - На вкладке "Faucets" используйте форму "Добавить новый кран"
   - Введите название, URL, тип криптовалюты и интервал
   - Нажмите "Добавить кран"

4. **Управление кранами:**
   - Включайте/отключайте краны чекбоксом
   - Удаляйте ненужные краны кнопкой удаления
   - Фильтруйте по типу криптовалюты

5. **Запустите автосбор:**
   - На вкладке "Dashboard" нажмите "Запустить автосбор"
   - Система будет автоматически собирать доходы
   - Отслеживайте доходы на панели управления

### Стандартные краны (предустановленные)

- **FreeBitco.in** - Классический BTC кран (60 мин интервал)
- **Moon Bitcoin** - Быстрый BTC кран (5 мин интервал)
- **CoinPot** - Мульти-крипто кран (15 мин интервал)
- **Eobot** - BTC кран с высокой доходностью (24 ч интервал)
- **Faucethub** - Агрегатор кранов (30 мин интервал)

## ⚙️ Настройки

### Хранение данных
Все данные сохраняются в браузере используя `localStorage`:
- Список кранов
- Адреса кошельков
- История доходов
- Настройки приложения

### Резервное копирование
На вкладке "Settings":
- **Экспортировать данные** - Сохранить JSON файл с резервной копией
- **Очистить все данные** - Удалить все сохраненные данные

### Восстановление данных
1. Экспортируйте данные в один браузер
2. Откройте JSON файл
3. Скопируйте содержимое
4. В другом браузере откройте консоль (F12)
5. Выполните:
   ```javascript
   const data = {...}; // скопированные данные
   localStorage.setItem('faucets', JSON.stringify(data.faucets));
   localStorage.setItem('earnings', JSON.stringify(data.earnings));
   localStorage.setItem('wallets', JSON.stringify(data.wallets));
   location.reload();
   ```

## 🔐 Безопасность

### Важные замечания

⚠️ **НИКОГДА НЕ:**
- Не делитесь приватными ключами
- Не публикуйте seed-фразы
- Не используйте простые пароли для кошельков
- Не вводите чувствительные данные на небезопасных сайтах

### Локальное хранилище
- Все данные хранятся локально в браузере
- Не передаются на внешние серверы
- Будут удалены при очистке кеша браузера
- Используйте резервные копии для важных данных

## 🐛 Решение проблем

### Service Worker не регистрируется
- Убедитесь, что используете HTTPS (или localhost)
- Проверьте консоль браузера (F12) на ошибки
- Очистите кеш браузера и перезагрузитесь

### Данные не сохраняются
- Проверьте, что localStorage включен в браузере
- Убедитесь, что у браузера есть разрешение на использование хранилища
- Попробуйте в приватном окне (может быть заблокирован)

### Приложение не устанавливается на мобильном
- Убедитесь, что используется HTTPS
- Проверьте, что manifest.json доступен
- Попробуйте другой браузер

### Автосбор не работает
- Проверьте, что включены все нужные краны
- Убедитесь, что браузер открыт (обычно требуется)
- Проверьте адреса кошельков на корректность

📖 Как использовать FaucetPay
1. Зарегистрируйтесь на faucetpay.io ↗
2. Добавьте ваши адреса кошельков BTC/ETH/LTC/SOL
3. Получите API ключ в разделе профиля
4. Вставьте ключ выше → Сохранить
5. Регистрируйтесь на кранах с тем же адресом что на FaucetPay
6. Краны автоматически выплачивают на FaucetPay
7. Когда накопите — выводите на основной кошелёк

📖 Как запустить бота
1. Telegram → @BotFather → /newbot → скопируйте токен
2. Telegram → @userinfobot → /start → скопируйте ID
3. Вставьте токен и Chat ID выше → Сохранить
4. Скачайте bot.js + package.json
5. Откройте bot.js → заполните CONFIG в начале файла
6. Задеплойте на Railway.app (бесплатно):
→ railway.app → New Project → Deploy from GitHub
7. Бот запустится и напишет вам в Telegram!
